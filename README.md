# Industrial Plant Supervisor

[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE) [![Status: planning](https://img.shields.io/badge/status-planning-64748b.svg)](#project-status)

**Software di supervisione e monitoraggio risorse.**  
Project by [RedHunt07](https://github.com/redhunt07).

This repository is the starting point for an industrial resource supervision and monitoring project.

## Project status

The repository currently contains this README and the [MIT license](LICENSE). Application source code, a runnable build, installation instructions and release packages have not yet been published.

## Collaborate

Use [issues](https://github.com/redhunt07/Supervisor-Industrial_Implant/issues) to propose concrete requirements:

- Which resources or equipment need monitoring.
- Which data sources, protocols and update intervals are required.
- Which operator workflows, dashboards and alerts would be useful.
- Which deployment environment the system should target.

These are topics for scoping the project, rather than implemented features. See [CONTRIBUTING.md](CONTRIBUTING.md) for how to contribute.

## Italiano
