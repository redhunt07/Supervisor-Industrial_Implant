# Contributing

This project is at the requirements stage. Start with an issue describing a concrete monitoring use case, target environment, data sources and expected operator workflow.

For a proposal, separate requirements from implemented functionality and explain how success could be verified. Discuss architecture and external dependencies before submitting a large implementation.

Documentation improvements and scoped prototypes are welcome. Keep examples free of credentials and private installation details. Label any prototype's limitations clearly.

There is no application build or automated test suite yet; do not report placeholder commands as validation. Contributions follow the existing [MIT license](LICENSE).
